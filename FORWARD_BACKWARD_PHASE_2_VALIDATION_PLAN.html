0 · Scientific question

Does the clean learner preserve the behavior that made both references work?

Phase 1 established equation tests, integration, GPU replay, checkpoint identity, and full-scale update feasibility. Phase 2 asks the missing empirical question: when attached to the unchanged native environments, does the same implementation reproduce MetaMotivo and BFM-Zero without hiding differences inside an adapter or a tuned evaluation?

Evaluation stateNative qpos/qvel, motion/time identity, and evaluator metadata; never learner replay.

BFM final-state selection

  1. Prefer a supported final-observation API.
  2. Otherwise use a narrow pre-reset wrapper hook.
  3. Otherwise benchmark reset-row-selective recomputation.
  4. If none is exact, stop the correct-terminal track.

Adapter acceptance

  • Exact field widths, dtypes, device, order, joint/action mapping, control rate, and reset semantics.
  • BFM history is field-major/newest-first; reset history and last action are zero.
  • Expert windows are contiguous, length eight, and motion-safe.
  • Boundary masks match hand-constructed reset traces.
  • Evaluation-only state never enters replay or observation routes.
  • Evaluators fail unless exactly 182 Meta or 862 BFM motion results exist.
  • BFM calls unchanged HumanoidVerseIsaacTrackingEvaluation; no EMD rewrite.

6 · Metrics and statistical law

Pair first, aggregate second, and never drop a difficult row

Every evaluator emits records keyed by (implementation, training_seed, evaluation_seed, motion_id, checkpoint_transition). Inner-join on every pairing key. Missing, duplicate, nonfinite, or unexpected rows fail validation.

\[\operatorname{AUC}=\frac{1}{t_K-t_0}\sum_{k=0}^{K-1}\frac{e_k+e_{k+1}}{2}(t_{k+1}-t_k).\]

Use exactly 10,000 paired percentile-bootstrap replicates from NumPy default_rng(20260626). The one-sided 95% upper bound is quantile 0.95. No interpolation, forward fill, unpaired interval, normal approximation, or post-hoc checkpoint choice.

Meta final gates

\[U_{.95}(\mathrm{EMD}_{new}-\mathrm{EMD}_{ref})\le\max(0.05,0.03\overline{\mathrm{EMD}}_{ref})\]
\[U_{.95}(\mathrm{AUC}_{new}-1.05\mathrm{AUC}_{ref})\le0,\qquad U_{.95}(\mathrm{PHC}_{ref}-\mathrm{PHC}_{new})\le0.03.\]

Seeds {0,1,2} are the outer bootstrap level; resample the 182 paired motions within seed and reuse that selection across checkpoints. Final EMD is 4.5M; AUC is the 0.5M–4.5M grid.

  • Write COMPLETE only after checkpoint, cardinality, finite-value, and hash validation.

2DMatched short learning runs

Test integration and learning direction with one expensive seed

  1. Meta seed 0: fresh source/candidate for 0.5M.
  2. BFM seed 4728: source/candidate under correct-terminal for 9.6M.
  3. Evaluate the released BFM checkpoint in native stochastic and deterministic harnesses as evaluator validation.

Observe without tuning

  • Replay readiness, cadence, contexts, expert sampling, reset mix, terminal counts.
  • All losses, reward channels, normalizers, target/online scale, actor scale, gradient/update norms.
  • First complete native metrics and paired per-motion deltas.
  • Throughput, memory, evaluator/checkpoint time, and disk.

Immediate stop

  • Any nonfinite state or incomplete metric.
  • Replay/boundary error, terminal overflow, or missing correct-terminal final.
  • Memory drift, <15% headroom, or host spill.
  • Cadence, mixture, assignment, or randomization mismatch.
  • Gross regression attributable to an unclassified mismatch.

2D is integration evidence, not non-inferiority. A noisy first point is reported, not optimized against. Any change invalidates and reruns the affected pair.

Stop and present short curves, diagnostics, full-motion metrics, terminal counts, and systems traces before 2E.
