Changed
^^^^^^^

* **Breaking:** Migrated :class:`~isaaclab_tasks.manager_based.multi_task.terrain.retarget.feature_extractors.FeatureExtractor` and the four bundled extractors (:func:`~isaaclab_tasks.manager_based.multi_task.terrain.retarget.feature_extractors.xyz_features`, :class:`XYZYawFeatures`, :class:`XYZAxisAngleFeatures`, :class:`XYZJointsFeatures`) from the old ``(buffer, valid_indices) -> features`` signature to a unified ``(states_slab) -> features`` signature, matching :class:`~isaaclab_tasks.manager_based.multi_task.curriculum.StateBuffer`'s ``fps_features`` API. Migration: extractors that previously read ``buffer.joint_q_result_t[valid_indices, ...]`` now operate directly on the passed-in slab — replace ``buffer.joint_q_result_t[valid_indices]`` with ``states`` and the rest of the body is unchanged.
* Routed the locomotion task-table builder's terminal FPS spatial-thinning step through :class:`~isaaclab_tasks.manager_based.multi_task.curriculum.StateBuffer` instead of the bespoke FPS body inside :meth:`RetargetPipeline.run`. The builder now sets ``skip_final_fps=True`` on the pipeline cfg, dumps every post-criteria candidate into a one-shot ``StateBuffer`` (capacity ``= n_candidates``, target ``= total_states``, same ``final_fps_features`` extractor), and calls :meth:`~isaaclab_tasks.manager_based.multi_task.curriculum.StateBuffer.compact` to thin. Same primitives, same numerical behaviour, single shared codepath.
