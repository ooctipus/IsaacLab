7.1 Reset order

  1. StateCommand samples a task row.
  2. The table returns clip and reset-time interval; table RNG samples reset source and time.
  3. The payload resolves reset columns into preallocated simulator-ready tensors.
  4. The selected reset transform applies fall/lie-down policy using the same RNG owner.
  5. The payload writes root and joint state to the live articulation.
  6. Reference clock, episode phase, tail state, history eligibility, and transition runtime reset atomically.

7.2 Reached/bootstrap selection

\[o_{t+1}^{reach}=\begin{cases}o^{final}_{t+1}&\text{same-step done and final-valid}\\o_t&\text{same-step done and final unavailable (counted approximation)}\\o^{returned}_{t+1}&\text{otherwise}\end{cases},\qquad c_t^{boot}=\mathbf 1[\neg terminated_t].\]

The learner chooses reached state once at transition reconstruction. Exact final is always preferred. Truncation bootstraps from the true final state; termination does not bootstrap but still needs the true reached state for evidence and timing.

7.3 History

Every history route declares source names, widths, order, length, update point, reset fill, and seed eligibility. G1 consumes processed action plus reached robot facts, excludes the external reset seed, and appends only applied transitions.

  • Preallocate per-environment clip/time/frame indices, interpolation scratch, reset state, reference outputs, history, evidence, and edge buffers.
  • No file I/O, source decoding, reference-model creation, per-environment Python, or duplicate trajectory corpus in step().
  • Runtime resolver writes into fixed tensors; table convenience views may allocate only outside the graph-critical path.
  • Use Torch until a representative benchmark and direct Warp capture test show a material gain.
  • Use upstream exact final observation; any selective final optimization belongs in the shared observation manager, not a motion patch.

12. Validation ladder

  1. Static source and axes: skeleton/clip identity, joint_names, reference_frame_names, shapes, dtypes, units, frames, interpolation.

  3. Table seal: exact capacity, ordered clips, named axes, identity, row coverage, clip-safe time ranges, probabilities.
  4. Single reset: one selected row into live root/joint state; compare current observation.
  5. Action/control: behavior, processed action, target, torque, next state.
  6. Short trace: 1/2/8/boundary steps; current/reached/history/evidence/reference elementwise.
  7. Final matrix: timeout/termination, final present/missing, native next-step reconstruction, tail.
  8. Vector scale: 1/16/1,024 environments, asynchronous done, clone invariance, allocation/synchronization checks.
  9. Systems: construction peak, resident table and expert memory, step/final/provider throughput.
  10. Learning integration: exact expert attachment, deterministic first-update canaries, then one production-semantics update and strict checkpoint reload in each native live environment.
  11. Convergence boundary: Phase 2 retains the separate predeclared algorithm non-inferiority gates. Phase 3 reran the environment-owned native reproduction needed to close the corrected root: the SMPL 0.5M–5.0M curve. It does not relabel this as cross-source or Phase 4 evidence.

14. Frozen decisions, rejected shortcuts, and open measurements

14.1 Frozen

  1. One environment class and one public preset name; normal direct config axes express compositions.
  2. scene.robot is the only physical robot object and the authority for live joint/body order.
  3. Source structure, reference kinematics, and live articulation meet only in the construction-time trajectory builder.
  4. MotionTaskTable owns trajectory columns, explicit axes, clip identity, descriptor rows, priorities, and RNG.
  5. joint_names and reference_frame_names are separate semantic axes.
  6. Payload owns per-environment reset/reference/history/evidence state; StateCommand remains a generic lifecycle shell.
  7. Environment exports named raw facts and exact final provenance; RSL-RL owns learned providers and value.
  8. Behavior/emitted action, current/reached/returned/final observation, and continuation masks remain distinct.
  9. Native reproduction precedes common timing and helper-provider migration.

14.2 Rejected

  • Separate Meta and BFM environment classes.
  • A giant caller-assembled environment constructor.
  • A second robot model, joint map, or body layout beside the scene articulation.
  • One packed unnamed width axis when named column groups expose semantics directly.
  • Runtime source decoding, FK, or source-format branches.
  • Learner-owned simulator teleport/reset caches.
  • One ambiguous expert window or reward scalar.
  • Profile fallbacks that hide a failed shared invariant.
  • Warp kernels without representative speedup and capture evidence.
  • Long convergence runs before deterministic edge parity.
